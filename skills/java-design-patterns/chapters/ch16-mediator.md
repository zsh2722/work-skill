# Chapter 16: 中介者模式

## Core Idea
集中管理一组对象之间的协作协议，避免每个对象直接知道所有其他对象。

## Frameworks Introduced
- **Mediator**：协作者只与中介者通信，中介者协调路由和顺序。
  - When to use：组件交互形成网状依赖，协议需要统一治理。
  - How：提取交互用例 → 中介者编排 → 协作者保持局部职责。

## Worked Example
原书手写 ORM：Mapper 调用交给 SQL Session，中介层解析映射、执行 JDBC、转换结果；业务不直接操作数据库细节。

## Modern Java
应用服务、消息总线和调度器可能承担中介角色。不要把所有领域规则集中到一个巨型中介；纯领域规则仍应属于聚合或策略。

## Anti-patterns
- 中介者变成拥有全部状态和规则的 God Object。
- 事件总线隐藏关键同步控制流。
- 通过字符串主题传递无类型消息。

## Key Takeaways
1. 中介者集中交互协议，不集中所有业务知识。
2. 关键命令用显式接口，松耦合通知才用事件。
3. 监控中介者的路由、延迟和失败。
